# 🏠 Rent-Property

A frontend Airbnb-inspired property rental website built as a part of my Git and web development learning journey.

## 📌 About the Project

Rent-Property is a frontend website inspired by Airbnb. The project focuses on creating a clean and user-friendly interface where users can explore different properties and view property-related information.

I built this project while learning Git, GitHub, and frontend web development concepts. It helped me understand how to manage a project using Git and maintain the project code on GitHub.

## ✨ Features

- 🏠 Property listing interface
- 🔍 Property search functionality
- 📍 Location-based property information
- 💰 Property pricing information
- 🖼️ Property images
- 📱 Responsive user interface
- 🎨 Clean and simple design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- React.js
